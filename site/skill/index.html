Notes inbox — skill generator

Makes a Claude skill that lets a note-taking session file notes to the book. Fill in the two values, download the zip, add it to that session.

The token never leaves this page. The zip is built here, in your browser, and handed straight to the download. This is a static file on GitHub Pages; there is no server behind it to send anything to.

Treat the zip as a credential. The token is written into the skill, because a Claude session has no other way to hold one. Anyone with the zip can file notes to the book. Rotating the token means changing NOTES_INTAKE_TOKEN and generating a new one here.

Not part of the book — that is over here.
