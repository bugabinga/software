Is this safe?

The zip is built in your browser and goes nowhere else — this page is a static file with no server behind it. The token is written into the zip though, so anyone holding it can file notes. Treat it as a credential.

Rotating it is three steps in order: change NOTES_INTAKE_TOKEN, run Worker deploy so Cloudflare gets the new one, then come back here for a new zip. Nothing runs that middle step for you.
